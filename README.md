# AI-инженер: вступительный модуль

Рабочая тетрадь из трёх разделов: программа курса, личные цели и план первой недели. Страница открывается без регистрации.

Ответы и 12 отметок сохраняются сразу после изменения в браузере на устройстве. Обновление страницы и повторное открытие сохраняют прогресс. Данные не отправляются на GitHub или сторонний сервер. Синхронизации между устройствами нет. Очистка данных сайта удаляет записи; в приватном режиме браузер может удалить их при завершении сеанса.

Это отдельная версия для GitHub Pages. Существующие записи на прежнем сайте остаются там и автоматически сюда не переносятся.

## Разработка

Node.js 22.13+.

```sh
npm ci
npm test
npm run dev
npm run build
```

Готовый сайт находится в `docs/`. GitHub Pages публикует эту папку из ветки `main`. При изменениях нужно пересобрать сайт и отправить обновлённые исходники вместе с `docs/`.

Проверка в браузере: `WORKBOOK_URL=http://localhost:4192/docs/ node tests/browser.mjs`. Нужен Playwright; пути задаются через `PLAYWRIGHT_MODULE` и `CHROMIUM_PATH` при отличии от локальной среды.
